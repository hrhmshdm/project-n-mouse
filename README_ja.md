# Project N-Mouse (ZMKファームウェア)

[English Documentation](README.md)

**ZMK Firmware (v0.3)** と Zephyr RTOS を採用した、自作超小型ワイヤレスマウスのファームウェアリポジトリです。

**Seeed Studio XIAO nRF52840 (BLE)** をメインMCUとし、光学センサー **PixArt PAW3395**、**TTC Green Core メカニカルロータリーエンコーダー**、静音マイクロスイッチ **Kailh Silent Micro Switch** を搭載しています。

---

## 💡 コンセプト・デザインの着想

本プロジェクトの外観デザインおよび透明シェルの意匠は、**Nothing Ear** の充電ケースからインスピレーションを受けています。そのミニマルで透明感のあるインダストリアルデザインを、オープンソースの超小型ワイヤレスマウスへ落とし込むことを目指しました。

## 📦 主なハードウェア部品 (BOM要約)

### アクティブ部品・センサー・スイッチ
- **光学センサー**: PixArt PAW3395 (1000 CPI デフォルト設定)
- **1.8V LDOレギュレーター (U3)**: Texas Instruments TLV74318PDBVR (SOT-23-5)[cite: 1]
- **主キースイッチ (左/右/サイド)**: Kailh 静音マイクロスイッチ (6x6x7.3mm, 2ピン) × 3
- **ホイールクリック (中ボタン)**: 薄型タクトスイッチ (4.5x4.5x4.3mm, TS-4501)
- **モード切り替えスイッチ**: タクトスイッチ (4.5x4.5x5.0mm, TS-4501)
- **電源スイッチ**: 小型スライドスイッチ (MSK12C01等)
- **ロータリーエンコーダー**: TTC Green Core メカニカルエンコーダー (12パルス / 24デテント)
- **バッテリー**: 3.7V 200mAh リチウムポリマー電池 (601230サイズ)

### 推奨受動素子 (0805 SMDサイズ)
- **チップ抵抗**: 10kΩ ±1% (R1), 4.7Ω ±1% (R2), 2MΩ ±1% (R3)[cite: 1]
- **チップコンデンサ**: 100nF 50V X7R (C2, C4, C5), 10µF 35V X5R (C3, C6), 47µF 10V X5R (C8), 1µF 50V X7R (C9, C11), 4.7µF 50V X5R (C1)[cite: 1]

## ⚙️ 主な技術的実装

### 1. ダイレクト1ノッチ整数スクロール (`zmk,behavior-encoder-mouse-scroll`)
- **ハードウェアプロファイル**: TTC Green Core の仕様に合わせた 12パルス / 24デテント設定 (`steps = <12>; triggers-per-rotation = <24>;`)。
- **低遅延処理**: 物理的な1ノッチごとに直接 HID レポート（`±1`）を送信。ソフトウェア的な浮動小数点慣性処理によるもたつきや誤判定を排除しています。
- **参照**: **elekit氏 (`elek1t`) のエンコーダースクロール動作** を ZMK v0.3 向けに移植・最適化しています。

### 2. センサー制御とモーション処理 (PAW3395 Driver)
- **ドライバ**: **[badjeff/zmk-paw3395-driver](https://github.com/badjeff/zmk-paw3395-driver)** を採用。
- **バス速度**: SPI2 を 4MHz にて駆動 (`CONFIG_SPI=y`, `CONFIG_INPUT=y`, `CONFIG_PAW3395=y`)。
- **割り込みピン**: NFC1ピン（`P0.09`）をGPIOとして割り当て (`CONFIG_NFCT_PINS_AS_GPIOS=y`)。
- **ドラッグスクロール (Layer 2)**: センサーのXY移動量を縦横のスクロール入力へとリマップ（`zip_xy_to_scroll_mapper`）。マウス本体を動かすだけで全方向への高速スクロールが可能です。

### 3. Bluetooth制御と省電力設計 (`prj.conf`)
- **デュアルプロファイル**: 切替のシンプル化のため、最大ペアリング数を2台に制限 (`CONFIG_BT_MAX_PAIRED=2`)。
- **低遅延BLE**: 接続間隔（コネクションインターバル）を 7.5ms〜11.25ms、2M PHY 有効で最適化。
- **通信輻輳対策**: `CONFIG_PAW3395_REPORT_INTERVAL_MIN=12` により、センサーレポート間隔を12ms（約83Hz）に制限してBLE通信の詰まり・パケットロスを防止。
- **スリープ制御**:
  - 無操作10秒でアイドル状態へ遷移。
  - 無操作10分でディープスリープへ移行（`CONFIG_ZMK_IDLE_SLEEP_TIMEOUT=600000`）。クリックまたはマウス移動で即時復帰。
  - 送信出力を -4dBm に設定し消費電力を抑制 (`CONFIG_BT_CTLR_TX_PWR_MINUS_4=y`)。
- **ステータス表示**: 内蔵RGB LEDにより接続状態やバッテリー残量をフィードバック（`zmk-rgbled-widget`）。

## 🖱 キーマップ・操作ガイド

> ℹ️ **注記**: 本キーマップは、作成者が Windows PC 上で事務作業・ドキュメント作成を効率化するために設定したものです。ZMKの仕様に基づき、お好みに応じて自由にカスタマイズ可能です。

### レイヤー 0: デフォルト（通常操作）
- **左クリック / 右クリック / 中クリック**: 通常のマウスボタン
- **左クリック ＋ 右クリック（同時押し）**: コピー (`Ctrl + C`)
- **サイドボタン（短押し）**: 戻る (`MB4`)
- **サイドボタン（長押し）**: 押している間 **レイヤー 1** へ移行
- **モードボタン（SW5 - 短押し）**: 次のBluetoothプロファイルへ切り替え (`BT_NXT`)
- **モードボタン（SW5 - 2秒長押し）**: 現在のBluetoothプロファイルのペアリング解除 (`BT_CLR`)
- **ホイール回転**: 垂直スクロール（1ノッチダイレクト）

### レイヤー 1: ナビゲーション（サイドボタン長押し中）
- **ホイール回転**: 水平スクロール (`SCRL_LEFT` / `SCRL_RIGHT`)
- **左クリック**: 進む (`MB5`)
- **中クリック**: タスクビュー (`Win + Tab`)
- **右クリック（短押し）**: ペースト (`Ctrl + V`)
- **右クリック（長押し）**: 押している間 **レイヤー 2 (システム・BT)** へ移行
- **左 ＋ 右クリック（同時押し）**: スニッピングツール (`Win + Shift + S`) ※専用マクロにより安定呼び出し
- **モードボタン（SW5）**: DFUブートローダーモードへ移行 (`&bootloader`)

### レイヤー 2: BT切替・システム管理（サイド ＋ 右クリック長押し中）
- **左クリック**: Bluetoothプロファイル 0 を選択 (`&bt BT_SEL 0`)
- **中クリック**: Bluetoothプロファイル 1 を選択 (`&bt BT_SEL 1`)
- **マウス移動**: 全方向高速ドラッグスクロール

## 🚀 ビルドと書き込み

1. 本リポジトリをフォークまたはクローンします。
2. `config/` 内の設定がハードウェア構成と一致していることを確認します。
3. `main` ブランチへプッシュすると、GitHub Actions による自動ビルドが実行されます。
4. 生成されたアーティファクト（`zmk.uf2`）をダウンロードします。
5. XIAO BLE をブートローダーモード（リセット2回押し）でPCに接続し、ドライブへ `.uf2` ファイルをドラッグ＆ドロップして書き込みます。
